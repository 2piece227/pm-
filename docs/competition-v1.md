## 3. 지방 구조 변경: 9개 지방 [확정]

```
kanto   관동        (신규 분리)
johto   성도        (신규 분리)
hoenn   호연
sinnoh  신오
unova   하나
kalos   칼로스
alola   알로라
galar   가라르
paldea  팔데아
```

- `INTERNATIONAL_REGIONS`에서 `kanto-johto`를 `kanto`, `johto` 두 개로 바꾼다. **이 배열 순서가 개최지 순환 순서다** (§8.2).
- 각 지방은 동일한 직위 구성을 가진다: **관장 8 · 사천왕 4(1~4번석) · 챔피언 1**.
  - 관동 관장 8명 = `GYMS.filter(g=>g.region==='kanto')`, 성도 관장 8명 = `region==='johto'`. 기존 진심 파티 그대로.
  - 관동 사천왕·챔피언 = 기존 `kanto-johto`의 사천왕 4명·챔피언 1명을 그대로 이관.
  - 성도 사천왕 4명·챔피언 1명 = **새로 생성** (생성 대표, 스탯 15/15/15/15/16, `buildParty(rng,'elite')`) — 기존 타 지방 생성 대표와 같은 방식.
- `PWT.gymRegions` 특례(관동·성도 16명 중 2명) 삭제. 모든 지방이 **관장 8명 중 2명** 선발로 통일된다 (SPEC §16의 "16명 vs 8명" 미결정 항목도 이걸로 해소).
- 팔데아: 원작의 "챔피언 랭크" 다수 보유 구조는 쓰지 않는다. 다른 지방과 똑같이 챔피언 1명(톱챔피언 자리)으로 취급한다 [확정]. 타운맵 없음은 문제없음(국제 지방은 대회 전용, 맵 해금 안 함 — 기존 규칙).
- 관전 대상 판정: 기존 코드의 `region==='kanto-johto'` 비교를 `['kanto','johto'].includes(region)`으로 바꾼다 (`international.js`의 `match()` 등, 저장소 전체 검색 필요: 현재 `kanto-johto` 문자열 사용처 15곳).

### 3.1 배지와 지방
- 배지는 이미 지방별(관동 8 / 성도 8)이다. **지역 리그 도전 자격은 해당 지방 배지 8개** (§9.3).
- 시티컵·로컬컵·타입컵의 `region:'kanto-johto'` 필드는 국내 대회 개최지를 뜻하므로 **그대로 둔다** (국내 리그는 통합).

## 4. 시리즈(다판제) 공통 규칙 [확정, 세부 임시]

### 4.1 형식
- `setFormat`: `'bo1' | 'bo3' | 'bo5'` (이벤트 객체에 이미 `setFormat:'bo1'` 필드가 있음 — 단계별로 지정할 수 있게 확장)
- 필요 승수: bo1=1, bo3=2, bo5=3. **필요 승수에 도달하면 즉시 종료** (남은 게임을 치르지 않음).
- 한 시리즈의 모든 게임은 **같은 날** 치른다.

### 4.2 게임마다 초기화
- 매 게임 HP/PP/상태/필드 전부 초기화 (기존 대회와 동일).
- 등록 파티 6마리, 기술, 도구, 특성, 레벨은 **시리즈 내내 고정**.

### 4.3 게임 사이 변경 허용 범위 [임시 — 설정값으로 분리]
2게임째부터, 각 게임 시작 전에 양쪽이 바꿀 수 있는 것:
1. **선봉 순서** (등록 6마리의 파티 순서)
2. **포켓몬별 전술 지시** (`tactics`)

바꿀 수 없는 것: 등록 포켓몬 교체, 기술, 도구, 노력치, 성격.

**NPC 기본 휴리스틱:**
- 직전 게임에서 졌으면: 상대가 직전 게임 선봉으로 낸 포켓몬에 대해 타입 상성 점수가 가장 좋은 내 포켓몬을 선봉으로 옮긴다. 나머지 순서는 유지.
- 이겼으면: 변경 없음.
- 동점이면 기존 순서 유지 (RNG 쓰지 않음 → 결정적).

**플레이어:**
- 플레이어 소속 선수가 나오는 시리즈이고 관전 모드(`watchMode==='watch'`)이면 게임 사이에 **선봉 순서·전술 변경 화면**을 띄운다. 기본값은 NPC 휴리스틱 결과로 미리 채워 둔다.
- 결과만 보기 모드면 NPC 휴리스틱을 자동 적용한다.

### 4.4 무승부
- 게임 단위로 기존 규칙(무승부 시 추첨 승자, `draw:true` 기록) 그대로.

### 4.5 데이터 구조 (제안)
```js
series = {
  id, eventId, stage, day,
  format: 'bo1'|'bo3'|'bo5',
  aId, bId,
  games: [matchId, ...],      // 기존 match 객체를 게임 단위로 재사용
  winsA, winsB,
  winnerId, loserId,
  adjustments: [{ game:2, side:'a', leadOrder:[...], tactics:[...] }, ...]
}
match에 seriesId, gameNo 필드 추가
```
- 단판도 시리즈 1게임으로 감싸서 모든 대회가 같은 코드 경로를 타게 한다.
- 시드 RNG: 게임마다 `seed = floor(game.rng()*0x7fffffff)` (기존 방식). 저장 후 불러와도 같은 결과가 나와야 한다(§16).

## 7. Road to PWT (지방 예선) — 9개 지방 공통 [확정]

기존 구현 구조를 유지하고 지방 수만 9개로 늘린다.

1. **관장 예선 (130일)**: 지방별 관장 8명 → 단판 토너먼트 2라운드(8→4→2) → 2명 선발. 대진은 셔플.
2. **지역 최종전 (138일)**: 관장 2 + 사천왕 4 = 6명을 셔플해 3명씩 A·B조. 조별 단판 리그(3경기). 각 조 1위 진출, 조 2위끼리 단판 최종 진출전 승자 진출.
   - 1-1-1 순환 동률은 기존대로 "동률 순환 · 추첨" 기록 후 추첨.
3. **지방 대표 4명과 시드** [신규]:
   - **1시드 = 챔피언** (예선 면제)
   - **2시드 = A조 1위**
   - **3시드 = B조 1위**
   - **4시드 = 최종 진출전 승자**
4. 대표 36명 중복 검사: `new Set(ids).size !== 36`이면 오류 (기존 32 검사를 36으로).
5. 대표는 **그 시즌 끝(365일)까지 이적·해지 잠금** (기존 유지).

## 8. PWT 본선 [확정]

### 8.1 전체 흐름
```
36명 (9개 지방 × 4)
 ├─ 1~3시드 27명 ─────────────────────────────┐
 ├─ 개최지 4시드 1명 ─────────────────────────┤→ 스위스 32명 → 16명 → 16강~결승 (전부 3판 2선)
 └─ 나머지 4시드 8명 → 플레이인 → 4명 통과 ──┘
```

### 8.2 개최지 [확정]
- 개최지 = `INTERNATIONAL_REGIONS[(PWT 개최 회차 - 1) % 9]`. 첫 PWT(개혁 모드는 2027 시즌, 비개혁은 1시즌)가 1회차 → **관동**, 다음 성도, 호연 … 순환.
- 개최지 혜택은 **그 지방 4시드의 플레이인 면제** 하나뿐이다.
- 시즌 생성 시 `s.host`에 저장하고, 시즌 시작 뉴스에 "올해 PWT는 ○○에서 열립니다"를 1회 띄운다.

### 8.3 플레이인 (148~149일) [확정]
- 참가: 개최지를 뺀 8개 지방의 4시드 8명.
- 4명씩 **A조·B조**로 추첨 (`game.rng` 셔플, 앞 4명 A조).
- 조별 **GSL 더블 엘리미네이션**, 전 경기 **3판 2선**:

| 경기 | 날짜 | 대진 | 승자 | 패자 |
|---|---|---|---|---|
| 개막 1경기 | 148 | 조 1번 vs 2번 | 승자전 | 패자전 |
| 개막 2경기 | 148 | 조 3번 vs 4번 | 승자전 | 패자전 |
| 승자전 | 148 | 개막 승자끼리 | **통과 (조 1위)** | 최종전 |
| 패자전 | 148 | 개막 패자끼리 | 최종전 | **탈락** |
| 최종전 | 149 | 승자전 패자 vs 패자전 승자 | **통과 (조 2위)** | **탈락** |

- 148일: A조 4경기 + B조 4경기 = 시리즈 8개. 149일: 최종전 2개.
- 통과 4명은 스위스에서 **"4시드" 등급**으로 취급한다 (§12의 동률 기준용).
- 탈락 4명의 PWT 순위: 공동 33위.

### 8.4 스위스 (150~154일) — §10 공통 규칙

### 8.5 녹아웃 (156~159일) [확정]

- 대진표: §12.3.
- 3·4위전 없음.

### 8.6 PWT 결과 처리
- 우승자 기록 (`honours`), 상금·평판 (§13).
- **PWT 우승자 PWC 혜택** [확정]:
  1. **개인**: PWC 출전 보장 (§11.1), PWC 스위스 1라운드 상대 우대 + 동률 최우선 (§10.3, §12.2)
  2. **지방**: 우승자의 지방은 PWC 플레이인 면제 (그 지방 4시드 직행)

## 9. 지역 리그 [확정, 수치 임시]

### 9.1 개요
- 9개 지방 모두 매 시즌 1회. 관동·성도는 플레이어 관여 지방이라 정밀(전체 배틀·로그 저장), 나머지 7개 지방은 배틀은 돌리되 로그를 저장하지 않는다 (§9.8).
- 결과는 **다음 시즌 직위**와 **이번 시즌 PWC 지방 시드 1~4**를 동시에 결정한다.

### 9.2 대진 구조
```
          8강 (3판 2선)              4강 (3판 2선)        도전자 결정전 (3판 2선)     챔피언전 (5판 3선)
위쪽  ┌ 사천왕 1번석 vs 도전자 4위 ┐
      │                             ├─ 4강 A ┐
      └ 사천왕 4번석 vs 도전자 1위 ┘         │
                                             ├─ 도전자 결정전 ── 최후 도전자 ── vs 현 챔피언
아래쪽┌ 사천왕 2번석 vs 도전자 3위 ┐         │
      │                             ├─ 4강 B ┘
      └ 사천왕 3번석 vs 도전자 2위 ┘

4강 A 패자 vs 4강 B 패자 → 3·4위전 = PWC 시드 결정전 (3판 2선)
```

### 9.3 도전자 선발 (279일 하루 끝) [확정]
- 자격: **등록 프로**(`isRegisteredPro`) + **해당 지방 배지 8개** + 현 챔피언·사천왕이 아님 + **관장이 아님** [미결정 — 기본: 관장 제외. 관장은 PWT 경로가 따로 있음. 설정값 `league.allowGymLeaders=false`]
- 무소속 프로도 시즌 순위가 있으면 자격 있음.
- 순서: 279일 하루 끝의 **시즌 순위(§5.2, 기존 `regional-ranking`)** 순.
- **관동·성도 양쪽 자격자 처리**: 한 리그만 출전한다.
  - 플레이어 소속: 지역 리그 화면에서 리그 선택 (기본값 아래 규칙), 마감 279일.
  - NPC·기본값: **배지 8개를 먼저 채운 지방**. 기록이 없거나 같은 날이면 관동.
  - 배정을 먼저 끝낸 뒤, 리그별로 자격자를 순위 순으로 정렬해 **상위 4명**을 도전자 1~4위로 확정 [확정: 선발전 없이 상위 4명 직행].
- **도전자가 4명 미만**이면 빈 자리의 사천왕은 8강 **부전승**. 도전자 0명이어도 리그는 열린다(4강부터 사천왕끼리).
- 279일 뉴스: "관동 리그 도전자 확정: A, B, C, D".

  - **챔피언 타이틀**: 챔피언전 당일 즉시 이전 (뉴스, `regionalRole` 변경). PWC에 새 챔피언이 1시드로 나간다.

- **도전자가 사천왕·챔피언이 될 때**: 소속사 소속 선수면 **소속은 유지**하고 `regionalRole`만 부여 (SPEC §5.1.1 관장 A안과 같은 방식) [임시]. 상금·평판은 소속사로 (`payCompetitionPrize` 기존 로직).
- **직위 상실한 사천왕**:
  - 원래 리그 소속 공식 인물(`official-*`, 소속사 없음)이면 → `personnel.freeAgents`에 무소속 프로로 등록 (스탯·파티 유지, 계약 요구 조건은 기존 FA 생성 로직). 뉴스: "○○, 사천왕 자리에서 물러나 FA 시장에 나왔다".
  - 소속사 소속 선수였으면 → `regionalRole`만 제거, 소속 유지.
- SPEC §5.1의 "자리를 비운 네임드는 비슷한 스탯 생성 캐릭터로 대체" 규칙은 **영입으로 비는 경우**에만 계속 쓴다. 리그 결과로 비는 자리는 위 표대로 채워진다.

### 9.7 전 챔피언
- 챔피언전에서 진 전 챔피언은 사천왕 1번석이 된다. 별도 "자동 출전" 규칙은 두지 않는다 (사천왕이면 다음 해 8강 자동 출전이므로 같은 효과). SPEC §5.1의 "전 챔피언 무조건 자동 출전" 문구는 이 의미로 고친다.

### 9.8 다른 7개 지방 리그
- 같은 대진·형식으로 관동 날짜에 처리. `keepLog=false`.

## 10. 스위스 스테이지 공통 (PWT·PWC) [확정]

### 10.1 규칙
- 32명, 같은 전적끼리 대결, **3승 진출 · 3패 탈락**, 5라운드.
- 하루 1라운드 (PWT 150~154, PWC 330~334).
- 현재 `swissPairs` (전적 그룹별 완전탐색, 재대결 금지) 유지·확장.

### 10.2 경기 형식 [확정]
- 기본 **단판**.
- 진출 또는 탈락이 걸린 경기 = **그 그룹의 승수가 2 또는 패수가 2**이면 **3판 2선**.

| 라운드 | 그룹 | 인원 | 시리즈 수 | 형식 | 결과 |
|---|---|---|---|---|---|
| 1 | 0-0 | 32 | 16 | 단판 | 1-0 16 / 0-1 16 |
| 2 | 1-0 | 16 | 8 | 단판 | 2-0 8 / 1-1 8 |
| 2 | 0-1 | 16 | 8 | 단판 | 1-1 8 / 0-2 8 |
| 3 | 2-0 | 8 | 4 | **3판 2선** | **3-0 4명 진출** / 2-1 4 |
| 3 | 1-1 | 16 | 8 | 단판 | 2-1 8 / 1-2 8 |
| 3 | 0-2 | 8 | 4 | **3판 2선** | 1-2 4 / **0-3 4명 탈락** |
| 4 | 2-1 | 12 | 6 | **3판 2선** | **3-1 6명 진출** / 2-2 6 |
| 4 | 1-2 | 12 | 6 | **3판 2선** | 2-2 6 / **1-3 6명 탈락** |
| 5 | 2-2 | 12 | 6 | **3판 2선** | **3-2 6명 진출** / **2-3 6명 탈락** |

- 합계: 단판 시리즈 **40개**, 3판 2선 시리즈 **26개** (결과와 무관하게 항상 같음 — 검증 §16에서 확인).
- 진출 16명 = 3-0 4명 + 3-1 6명 + 3-2 6명 (항상 고정).

### 10.3 대진 제약
**1라운드** (우선순위 높은 것부터, 해가 없으면 낮은 것부터 하나씩 풀어 재시도):
1. [PWC만] **PWT 우승자는 4시드 등급(플레이인 통과자·직행 4시드) 중 다른 지방 선수와** 대결
2. 같은 지방끼리 금지 (기존)
3. 1시드(챔피언)끼리 금지 (신규)

**2라운드**: 같은 지방끼리 가능하면 금지 (해 없으면 해제).

**3~5라운드**: 재대결 금지만.

- 재대결 금지는 모든 라운드에서 절대 조건 (기존 코드처럼 해가 없으면 오류 — 32명 5라운드 구조에서는 발생하지 않음).

## 11. PWC [확정]

### 11.1 출전권: 지방당 4장, 총 36명
1. 각 지방 지역 리그 결과로 시드 1~4 (§9.5).
2. **PWT 우승자 처리**:
   - PWT 우승자가 이미 자기 지방 1~4시드 안에 있으면 → 변동 없음.
   - 4시드 밖이면 → **4시드 자리를 가져간다** [확정]. 원래 4시드(3·4위전 승자)는 미출전. 뉴스: "PWT 우승자 ○○가 관동 4시드를 가져갔다. ○○(3·4위전 승자)는 PWC 출전이 무산됐다."
   - PWT 우승자의 "자기 지방" = PWT 출전 당시 대표 지방 (`representative.region`). 이후 직위 상실·이적 잠금과 무관.
   - PWT 우승자가 이 시점에 직위가 없거나(사천왕에서 밀려남, 단 반영은 다음 시즌) 관장이어도 출전.
3. 3·4위전은 PWT 우승자가 4시드를 가져가도 **그대로 연다** (사천왕 3·4번석 결정용).
4. 36명 중복 검사 (`Set` 크기 36).

**참고 (시뮬레이션 결과, §16.3):** 관장은 지역 리그에 나가지 않으므로, **관장이 PWT를 우승하면 그 지방 3·4위전 승자는 항상 PWC에 못 나간다.** 전체 시즌 기준으로 약 절반의 시즌에서 한 지방의 4시드가 밀려난다. 의도된 결과로 확정.

### 11.2 등록 마감 (315일)
- 315일 하루 끝에 36명의 6마리 파티를 스냅샷 (Lv50 고정, `snapshotEntry` 재사용).
- PWC 대표는 315일부터 365일까지 이적·해지 잠금.

### 11.3 플레이인 (328~329일)
- **PWT 우승자 지방의 4시드는 직행**. 나머지 8개 지방 4시드 8명이 플레이인.

- 직행 4시드가 PWT 우승자 본인일 수 있다 (정상).
- 스위스 입장: 1~3시드 27 + 직행 4시드 1 + 통과 4 = 32.

### 11.4 스위스 (330~334일) — §10. 1라운드 PWT 우승자 제약 적용.

## 12. 시드·동률·대진표

### 12.1 국제 대회 시드 등급
- 1시드(챔피언) > 2시드 > 3시드 > 4시드(직행·플레이인 통과 포함).

### 12.2 동률 기준 (스위스 같은 전적 안)
1. 부흐홀츠 (만난 상대들의 **최종** 스위스 승수 합) 높은 순
2. [PWC만] PWT 우승자 우선
3. 시드 등급 높은 순
4. 맞대결 승자 (만났다면)
5. 시즌 시작 시 고정 셔플 순서 (`s.tiebreakOrder`, 저장)

### 12.3 녹아웃 대진표
- 스위스 진출자 순위: 3-0 → 1~4번, 3-1 → 5~10번, 3-2 → 11~16번, 같은 전적 안은 §12.2.
- 배치: 기존 `seedOrder(16)` (1 vs 16, 8 vs 9, …). 결과적으로 3-0 4명은 3-2와, 3-1 중 5·6번은 3-2와, 7~10번은 3-1끼리 만난다.
- **16강 같은 지방 회피**: 같은 지방끼리 붙는 쌍이 있으면, 그 쌍의 아래 시드 선수를 **같은 전적 그룹 안**의 다른 아래 시드 선수와 교환해서 해소한다. 교환으로 새 같은 지방 쌍이 생기면 다른 후보를 시도. 해가 없으면 그대로 두고 로그에 남긴다. 전적 그룹을 넘나들며 바꾸지 않는다.
- 8강부터는 대진표대로 진행 (재배치 없음).

## 16. 저장 호환·마이그레이션

### 16.1 원칙
- 저장 버전 +1. 기존 저장은 그대로 불러와져야 한다.
- **진행 중인 시즌의 PWT는 구 구조(8지역)로 끝까지 진행**한다. `internationalSeason`이 이미 만들어졌고 `status`가 `'scheduled'`가 아니면 건드리지 않는다.
- 새 구조(9지방)는 **아직 시작 안 한 PWT부터** 적용.

### 16.2 공식 인물 이관
- `game.international.regions`의 `kanto-johto` 항목 → `kanto`(관동 관장 8 + 기존 사천왕 4 + 기존 챔피언) + `johto`(성도 관장 8 + 신규 생성 사천왕 4 + 신규 생성 챔피언).
- 기존 `official-kanto-johto-*` id는 **바꾸지 않는다** (경기 기록 참조 유지). `region` 필드만 `kanto`로.
- 과거 `honours`/경기 기록의 `kanto-johto`는 표시할 때 "관동·성도"로 보여 준다.
- 구 `s.pwcAuto.extraSeed` 필드는 읽을 때 무시.

### 16.3 이미 지난 날짜
- 마이그레이션 시점보다 날짜가 지난 신규 이벤트(타입컵 등)는 만들지 않는다 (기존 `date>=game.day` 규칙).
- 로컬컵 유스부가 이미 만들어진 저장: 날짜가 안 지났고 등록자가 없으면 삭제, 등록자가 있으면 그해만 유지.

### 21.3 직위 = 지역 리그 소속 [확정, 수치 임시]
- 지역 리그에서 사천왕·챔피언 직위를 얻으면 **소속사를 떠나 그 지방 리그 소속**이 된다. PWT·PWC에는 "○○ 리그" 대표로 나간다. (§9.6의 "소속 유지 + regionalRole만 부여"를 대체)
- 연봉은 리그가 선수에게 준다. 대회 상금·평판은 선수 본인 몫(소속사 없음).
- 원 소속사는 떠날 때 **이적 보상금**을 한 번 받는다: 사천왕 10,000 / 챔피언 20,000 [임시].
- 반영 시점은 §9.6과 같다: 챔피언은 챔피언전 당일, 사천왕 석 이동·신규 사천왕은 다음 시즌 1일차.
- **직위에서 내려올 때**(다음 시즌 1일차, 또는 챔피언 타이틀을 잃어 사천왕 1번석으로 내려가는 경우는 직위 유지):
  - 원 소속사가 있으면 그 소속사가 **우선 협상권**을 가진다. 스토브리그(1~28일) 동안 원 소속사만 계약할 수 있고, 지나면 일반 FA로 풀린다.
  - 원 소속사가 없던 선수(공식 인물·무소속 출신)는 바로 FA.
- 소속사 로스터에서 빠지므로 프로 좌석도 비고, 소속사는 그 자리를 새로 채운다.
